PostalIQ Orders Register UI update

1. The runtime site uses ONLY index.html.
2. data/orders.json remains the master runtime order register.
3. Orders Register now has a Year selector. Selecting a year shows only that year's orders.
4. Order detail opens in a large 82vh / 88vw reading window with internal scrolling.
5. Added explicit Close Window button, X button, Escape-key close, and A-/A/A+ text-size controls.
6. Order number is displayed prominently in bold.
7. Order subject and body typography have been enlarged and polished for long-form reading.
8. The known trailing OCR artefact in SB Order 08/2022 was removed from the runtime JSON display text.
9. Supersession relationships have NOT been inferred or changed in this update.
